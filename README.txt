MyWords

Como usar:
1. Extraia o ZIP.
2. Abra o arquivo index.html no Chrome ou Edge.
3. Clique em "Novo texto".
4. Escreva. O sistema salva automaticamente no navegador.
5. Use a lista lateral para abrir outros textos.
6. Use "Baixar Word" para gerar o arquivo.

Observação:
- O MyWords guarda os textos no armazenamento local do navegador (localStorage).
- Os textos ficam neste computador/neste navegador.
- O download .docx usa a biblioteca docx carregada pela internet.
- Se a biblioteca não estiver disponível, o sistema tenta gerar um .doc compatível com Word.
